# BDA International — landing

Static one-page site (Spanish / English toggle). No build step.

- `index.html` — page, styles and scripts (texts for both languages live in the `T` object in the script).
- `assets/` — hero carousel, project galleries, team photos and partner logos.

## Deploy on Vercel

New Project → import this repository → **Root Directory: `bda-web`** → Framework preset: **Other** → Deploy.

## Team contact links

WhatsApp numbers and LinkedIn URLs per person are set in the team cards (`wa.me/...` and LinkedIn links). Missing ones render as a dimmed icon.
